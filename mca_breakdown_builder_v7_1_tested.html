Default factor rate

              

                

                  
                  
                

                

                  
                  
                

              

              
This default is used for new positions. Every saved position preserves its own effective factor rate.

            


            

              
Catalog reset

              
Restores original CSV names and categories, removes favorites, and clears local catalog overrides. Custom entries are preserved unless deleted separately.

              
            

          


          

            

              
How factor rates work

            

            

              
Default behavior

              
New normal and refinance positions use the saved default factor rate. The initial value is 1.600.

            

            

              
Exceptional position

              
Inside Add position, enable Use a custom factor rate and enter a different value. The override affects only that position.

            

            

              
Historical stability

              
Changing the default does not recalculate positions that were already saved. Their effective rate is stored with the position.
